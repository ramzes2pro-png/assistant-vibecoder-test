# Тестовое задание — ассистент-вайбкодер

[Открыть оформленное решение](https://ramzes2pro-png.github.io/assistant-vibecoder-test/)

Четыре задания: оценка звонков, сводка по лидам, памятка ученику и отчёт о работе.

- [Звонки: HTML](01-звонки/итоги.html), [таблица CSV](01-звонки/оценки.csv).
- [Лиды: HTML](02-лиды/сводка.html), [скрипт Python](02-лиды/leads.py), [инструкция](02-лиды/КАК-ЗАПУСТИТЬ.txt), [результат JSON](02-лиды/результат.json).
- [Памятка: HTML](03-памятка/памятка.html).
- [Отчёт: HTML](04-отчёт/отчёт.html), [лог использования ИИ](04-отчёт/лог-промптов.txt).

Для просмотра без интернета скачайте репозиторий целиком и откройте `index.html`.
Шрифты и стили встроены в страницы; сервер и установка зависимостей для просмотра не нужны.

Повторный расчёт лидов: `python3 02-лиды/leads.py`. Нужен Python 3.9+; сторонних библиотек нет.
Исходные данные находятся в папке `данные`. Допущения описаны на страницах результатов.
